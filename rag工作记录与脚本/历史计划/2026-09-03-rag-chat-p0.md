# RAG and Chat P0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Keep the existing router/subagent contracts while making Chat and RAG executable with configurable LLM/embedding providers and a local fallback.

**Architecture:** Add configuration-backed model clients behind small interfaces, split RAG parsing/chunking/index-search responsibilities, and let the orchestrator compose retrieval context into an LLM prompt. Existing DTOs and route precedence remain compatible.

**Tech Stack:** Spring Boot 3.3, Java 17, Apache PDFBox/POI, Java HttpClient, JUnit.

## Tasks

1. Add model configuration (`application.yml`, `ModelProperties`) and provider clients with deterministic local fallback; test configuration and fallback behavior.
2. Replace simplistic ingestion with parser/chunker/index services supporting PDF, Word and Excel metadata; test each supported input and parent-child relationships.
3. Implement hybrid retrieval (keyword plus embedding cosine score) and parent-context expansion; test ranking and evidence fields.
4. Implement Chat/RAG orchestration: execute retrieval for RAG, call LLM, return evidence refs and failure/degraded statuses; test both routes and unavailable model behavior.
5. Run backend and frontend verification, update README with configuration and API examples.
