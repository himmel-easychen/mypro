# 分析模式

目标：让用户知道项目要求什么、企业能证明什么、哪些项可能失分或被否决、还需决定什么。以资料员交付的可读材料和来源索引为输入，未读取部分作为覆盖缺口保留。

## 分析顺序

1. **项目与范围**：提取项目/标段、采购内容、截止时间及时区、工期、资格条件、合同范围和投递方式。存在多标段时确认用户关注范围；独立分析已明确部分。
2. **拆解要求**：将资格、技术、服务、商务、提交格式等要求拆为可核对的单项，保留原文、强制性和来源。否决性条件与一般评分项分别标记，不能互相替代。
3. **还原评分办法**：登记各项分值、取分条件、证明材料、计算方法、上限及互斥关系。价格分与技术/商务分分别处理；未知竞争对手报价时不要给出确定价格得分。
4. **提交与报价规则**：整理规定目录、表格、签章、附件、份数、文件格式，以及含税/不含税、币种、单价/总价、分项范围和报价有效期。
5. **匹配企业证据**：核对资质主体、有效期、项目性质、人员条件等。给每项要求标记“充分支撑、部分支撑、缺失、待核对、不适用”，说明判定理由。用户口头说明与正式证明分别记录。
6. **估计机会与风险**：能计算的得分按规则计算，列出输入与假设；条件不确定的项目给出条件区间或待确认状态。强制要求缺证、材料矛盾、补遗冲突进入风险表。
7. **形成策略候选**：在现有证据和用户边界内提出可执行方案，比较覆盖要求、可证明得分、补材料工作量、承诺风险和时间。方案数量按实际有意义的差异决定。
8. **输出协作议题和初步目录**：优先列出决定投标可行性或后续生成的事项。目录遵守招标文件要求，存在冲突时标明需澄清的位置。

## 审查与阶段门槛

审查员从原始资料抽查关键金额、日期、资格/否决条款和高权重评分项。检查要求、评分、证明和拟回应内容的对应关系，确认未把历史业绩、过期证书或另一主体材料误当当前有效证明。

分析完成意味着：已读范围明确，关键要求有来源，证据缺口显式可见，未决判断没有伪装成事实。缺少企业材料不妨碍完成招标要求分析，但企业符合性、得分预计和具体承诺必须标为未确定。

## 用户可见交付

- 项目要点和优先处理的阻塞风险。
- 要求/证据矩阵，评分机会与假设。
- 提交结构与报价规则，缺失材料清单。
- 可选策略及代价、需要用户决定的协作议题、初步响应目录。

根据请求范围合并展示，避免让用户阅读一长串内部产物名称。用户只问局部条款时只交付相应分析与来源。
