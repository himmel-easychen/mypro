# 上传材料后的整理流程

由资料员执行，主控验收。输入是宿主提供的附件、文件句柄或其可访问的内容；全程使用当前宿主的阅读、视觉、检索和存储能力。

## 1. 登记并分类

为每份文件分配稳定资料 ID，保留原始文件名、版本/日期、业务角色和可读状态。角色包括：招标正文、补遗答疑、技术要求、评分办法、合同/商务条款、报价表、强制格式、企业证明、历史参考、未知。

文件名只能用于初步判断，阅读内容后确认。文件相同或疑似重复时比较已有可用元数据或内容；宿主能计算指纹时可以使用，不要求必须计算。重复上传引用已有资料记录，避免重复统计证据。补遗与旧版建立明确对应关系。

## 2. 读取与质量判断

- PDF/Word：检查目录、文件页数或可访问范围、关键章节及附件。长文件按目录分段，不以几条搜索命中代替全文覆盖判断。
- 扫描件/图片：调用宿主 OCR 或视觉能力；重点核对金额、日期、否决性条款和表格单元格。不可辨认内容记为未知。
- Excel：保留工作表名、表头、单位、币种、税口径、合并单元格和公式/显示值的区别。
- 历史标书：登记为参考资料，里面的人员、报价、资质和旧承诺不能直接成为本项目已确认内容。

记录实际读取范围、失败范围及其影响。只读了部分内容时标为“部分可读”，不要报告全部材料已处理。

## 3. 建立可检索的资料索引

优先使用宿主自带附件索引或文件搜索，保留其返回的来源定位。无专用检索时，在工作记录中维护文件—章节—内容主题的索引，按后续问题返回相应原文；可分批读取或保存提取笔记。

每个可引用片段包含：资料 ID、真实位置、原文片段或准确摘要、版本、识别疑点。相关表格的标题、表头、单位、脚注和数据行应一起保留，避免拆开后误读。

对“资格/否决条件”和“评分规则”各找一处实际原文，检查索引能否定位回来源。范围内不存在此类内容时记录缺失，不虚构检索命中。

## 4. 交给分析角色

交付材料目录、版本关系、可读范围、关键来源入口和读取问题清单。说明索引只在当前会话有效，还是已保存在宿主工作空间；只有真实持久化后才能声称后续可直接复用。

用户同时提出问题时，完成足以回答该问题的资料核对后继续回答，不强制为单个问题生成全部项目档案。

## 新材料如何影响已有成果

将新增内容关联到受影响的要求、评分项、证据、决策和章节。补遗修改投标截止时间时，更新项目摘要及相关交付检查；企业新增业绩证明时，更新证据覆盖和相关评分估计。保留旧结论失效原因，重新审查受影响内容即可。
